\textbf{Group members:} Sunay Master, Matthew Purkiss, Harshil Vallabh

\textbf{Project:} \emph{Erased and penalised: 19th-century isiXhosa newspapers in modern NLP pipelines}

\textbf{Research question.} When the isiXhosa newspapers \emph{Isigidimi samaXosa} (1870--1888) and
\emph{Imvo Zabantsundu} (1884--1894) from the isiXhosa Intellectual Traditions corpus
(Schoots et al., 2023) are passed through a modern NLP pipeline, how much of the text is filtered
out, and how much worse is it modelled? How much of that penalty comes from fixable spelling
differences rather than genuine linguistic or cultural change?

\subsection*{Sunay Master}
\begin{itemize}
  \item Run the filters used to build LLM training data (language ID, Gopher quality rules, C4
        bad-words list, perplexity filter) on historical isiXhosa, historical English and modern
        isiXhosa, and measure how much of each survives.
  \item Find which filters remove the most text, and run them again on spelling-normalised text.
  \item Look at examples of removed text to see what kind of content is lost.
\end{itemize}

\subsection*{Matthew Purkiss}
\begin{itemize}
  \item Collect modern isiXhosa text (MasakhaNEWS, isiXhosa Wikipedia).
  \item Build a normaliser that converts historical spelling to modern spelling
        (e.g.\ \emph{kuti} $\rightarrow$ \emph{kuthi}), and check its accuracy on a hand-checked word list.
  \item Measure how much more modern tokenisers split up historical text than modern text.
\end{itemize}

\subsection*{Harshil Vallabh}
\begin{itemize}
  \item Corpus statistics, and train/validation/test splits by newspaper edition.
  \item Train character language models on raw vs normalised text, with and without added modern
        data, tuned on the validation set and evaluated once on the test set.
  \item Combine all results to show how much of the gap with modern text is due to spelling.
\end{itemize}

\subsection*{Shared by all members}

  \item The two-page extended abstract (PDF), the full code, and checking every reference.
  \item The final contribution statement, which will report any changes to this plan and why.
\end{itemize}
